## Featured Projects

### [Bar Buddy](https://github.com/mrnoahjwilliams/bar-buddy)

A publicly deployed home-bar and cocktail discovery application built with Java, Spring Boot, PostgreSQL, React, and TypeScript.

Bar Buddy tracks bottle-level inventory and compares it against a curated catalog of 102 cocktails to determine what each user can make, what ingredients are missing, and which drinks are one ingredient away.

**Backend:** Java 25 · Spring Boot · Spring Security · JPA/Hibernate · PostgreSQL · Flyway  
**Frontend:** React · TypeScript · Vite · TanStack Query · Tailwind CSS  
**Infrastructure:** Supabase Auth/PostgreSQL · Docker · Vercel · Render  
**Engineering:** REST APIs · OpenAPI · Testcontainers · GitHub Actions · Automated Testing · Protected PR Workflow

[Live Application](https://barbuddy.projects.williamsestate.net) · [Source Code](https://github.com/mrnoahjwilliams/bar-buddy)
